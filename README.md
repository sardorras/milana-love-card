# Открытка для Миланы 💌

Романтическая одностраничная открытка на чистых HTML, CSS и JavaScript. Фреймворки, сборка и зависимости не нужны.

## Запуск локально

Откройте `index.html` в браузере или запустите в папке проекта `python3 -m http.server 8000`, затем перейдите на `http://localhost:8000`.

## Публикация через GitHub Pages

1. Откройте репозиторий [sardorras/milana-love-card](https://github.com/sardorras/milana-love-card).
2. Перейдите в **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main`, папку `/(root)` и нажмите **Save**.
5. После публикации сайт будет доступен по адресу `https://sardorras.github.io/milana-love-card/`.

Фоновая музыка необязательна. Чтобы добавить её, загрузите собственный файл `music.mp3` в корень репозитория. Шрифты загружаются из Google Fonts; без сети используются системные шрифты.
